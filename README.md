"The Museum of Lost Seconds" — a top-down 2D stealth game. Steal the glowing second from a clockwork museum across 3 handcrafted galleries: WASD to move, click to toss a wind-up moth that lures guards, hide behind exhibits, watch the guards' vision cones (grey UNSEEN, amber NOTICED, red HUNTED), and reach the EXIT unseen. Built for the make.fun bounty best-stealth-game-20261121-1759 ($50, 10 paid places).

## Run it

```sh
python3 -m http.server 8080 --directory game
# then open http://localhost:8080 — WASD move, click toss moth, E exit, R restart
MAKEFUN_OUTPUT_DIR=out node main.ts
```
